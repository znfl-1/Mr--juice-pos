MR CASHIER — آخر نسخة 5.14

تحديث الويب:
ارفع ملفات الويب الموجودة في جذر هذا الملف إلى جذر مستودع GitHub نفسه، واستبدل الملفات القديمة. لا ترفع ملف ZIP نفسه بدلاً من الملفات.
Vercel: Build Command = npm run build، Output Directory = dist، Framework = Other.
مجلد printer-agent مخصص لجهاز الطباعة ولا يحتاج للرفع ضمن ملفات الويب.
قاعدة بيانات المشروع الحالي مُحدّثة بالفعل؛ لا تحتاج إعادة إنشائها.

تحديث وسيط الطباعة في Termux:
1. أوقف النسخة القديمة بـ CTRL+C، وخذ نسخة احتياطية من مجلد printer-agent.
2. انسخ printer_agent.py وlogo.png وrequirements.txt ومجلد fonts من مجلد printer-agent الجديد إلى مجلد التشغيل القديم.
3. حافظ على .env وprinted_orders.sqlite3 وأي receipt_settings.json مخصص عندك. لا تحذف سجل الطباعة لأنه يمنع إعادة طباعة الطلبات.
4. receipt_settings.example.json مثال فقط؛ لا تستبدل به إعدادات إيصالك المخصصة إلا لو أردت استعادة الشكل الافتراضي.
5. داخل مجلد التشغيل نفّذ:
pip install -r requirements.txt
python printer_agent.py
شغّل وسيطاً واحداً فقط. اختبر بطلب جديد من الويب: عند الإرسال للمطبخ تطبع ورقة التجهيز والمطبخ، وعند التحصيل يطبع إيصال العميل حسب إعدادات الأدمن.

الإصدار: 5.14 للويب ووسيط الطباعة.
