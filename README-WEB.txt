شاشة الطلبات: قائمة مع البحث برقم الطلب أو الصنف أو العميل أو الموظف، وتفاصيل الطلب المختار بجانب القائمة على التابلت.
قفل التذكرة يفتح ملخص الطلب واختيار الدفع وحساب الباقي، مع حماية من تكرار تأكيد الدفع.
الإلغاء ما زال يتطلب رمز الأدمن للكاشير، والتحصيل يبقى للكاشير. الوسيط الحالي 5.17 مناسب ولا يحتاج تحديثاً لهذا التعديل.

نجح التجميع والاختبارات المحاكية للواجهة والبحث والتحصيل والإلغاء والعهدة. يلزم تجربة الواجهة على الهاتف والتابلت فعلياً.
